# Roadmaps

Longer-term skill progression. For short routes use [learning paths](../learning-paths/); for Read→Build→Practice use the [Learning Matrix](../learning-paths/learning-matrix.md).

## Default progression

```text
Junior / early DevOps
        ↓
Containers
        ↓
Kubernetes
        ↓
Terraform / IaC
        ↓
GitOps
        ↓
Security (DevSecOps)
        ↓
Observability / SRE
        ↓
Platform Engineering
```

