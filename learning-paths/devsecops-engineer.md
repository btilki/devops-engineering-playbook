# Learning Path: DevSecOps Engineer

## Outcome

Embed security early in the platform lifecycle: scanning, policy as code, and secure delivery on Kubernetes.

## Milestones

1. Threat-aware delivery basics
2. Image and dependency scanning
3. Policy as code on the cluster
4. Pipeline gates and evidence
5. Connect to GitOps and SRE practices
