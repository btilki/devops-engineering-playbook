# Learning Path: GitOps Practitioner

## Outcome

Operate Git-driven delivery on Kubernetes with Helm and continuous reconciliation (e.g. Argo CD).

## Milestones

1. Git as the source of truth
2. Helm packaging and environments
3. Argo CD application model
4. Promotion patterns (dev → staging → prod)
5. Relate delivery to security and reliability
