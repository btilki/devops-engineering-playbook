# Learning Paths

Structured routes from fundamentals to platform-level practice.

| Path | Outcome |
|------|---------|
| [DevOps Engineer](./devops-engineer.md) | Automation, CI/CD, IaC, Kubernetes foundations |
| [GitOps Practitioner](./gitops-practitioner.md) | Git-driven delivery on Kubernetes |
| [DevSecOps Engineer](./devsecops-engineer.md) | Shift-left security and policy as code |
| [Site Reliability Engineer](./site-reliability-engineer.md) | Reliability, observability, operations |

## Default progression

```text
Containers → Kubernetes → Terraform / IaC
        → GitOps → Security (DevSecOps)
        → Observability / SRE → Platform Engineering
```

Each path file lists milestones, suggested projects, and related reading.
