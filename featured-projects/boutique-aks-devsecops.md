# Boutique AKS DevSecOps

**Repository:** [btilki/boutique-aks-devsecops](https://github.com/btilki/boutique-aks-devsecops)

## Summary

Security-first Kubernetes delivery on Azure Kubernetes Service. Emphasizes shift-left scanning, policy as code, and DevSecOps workflows integrated into the platform lifecycle.

## Focus areas

- Azure Kubernetes Service (AKS)
- DevSecOps
- Policy as code
- Supply-chain and image security practices

Shipping fast without security controls creates risk. This project shows how security can be embedded early in the delivery path on a real cloud Kubernetes platform.
