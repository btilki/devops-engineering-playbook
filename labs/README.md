# Hands-on Labs

Entry points into labs hosted in the featured repositories.

| Lab | Cloud | Difficulty | Upstream |
|-----|-------|------------|----------|
| GitOps on EKS | AWS | Intermediate | [boutique-eks-gitops](https://github.com/btilki/boutique-eks-gitops) |
| DevSecOps on AKS | Azure | Advanced | [boutique-aks-devsecops](https://github.com/btilki/boutique-aks-devsecops) |

## How to use

1. Read the matching [architecture](../architecture/) note.
2. Open the upstream repository README and lab docs.
3. Follow the learning path for your domain.
4. Capture lessons for articles and LinkedIn storytelling (private `campaign/` workspace).

Lab-specific playbook pages can be added here as `lab-*.md` files when needed.
